# netflix-webpage


A simple Netflix-style webpage created using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Netflix-style navigation bar
- Hero section
- Trending movies
- Popular movies
- Movie search
- Play and More Info buttons
- Responsive design
- Hover effects

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. You can also use Live Server in VS Code.
